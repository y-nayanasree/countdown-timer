# Countdown Timer ⏳

A responsive countdown timer built as part of my Web Development Internship at Veda Technology.

## Features

- Displays remaining days, hours, minutes, and seconds
- Automatically updates every second
- Shows a completion message when the countdown reaches zero
- Configurable target date
- Responsive design for desktop and mobile screens
- Attractive UI with hover effects

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

- `index.html` - Webpage structure
- `style.css` - Styling and responsive layout
- `script.js` - Countdown functionality
- `README.md` - Project documentation

## Target Date

December 31, 2026, at 11:59:59 PM.

## How to Run

1. Open `index.html` in a web browser.
2. The countdown starts automatically.
3. Change the target date in `script.js` if needed.
